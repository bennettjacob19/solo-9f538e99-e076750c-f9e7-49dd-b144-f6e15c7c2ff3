# 遥测 UDP 代理（接收器 A/B 切换 + 会话配额控制）

遥测终端经 UDP 代理把短报文发给接收器，值班员在网页上切换接收器 A/B；
独立运行的**配额控制服务**提供网页设置全局/单来源会话上限，防止异常终端
不断更换 UDP 源端口占满代理的上游端口。

## 组成

| 组件 | 说明 |
|---|---|
| `proxy/` | asyncio UDP 代理 + Flask 操作网页 + SQLite 持久化；负责会话与配额执行 |
| `quota/` | **独立配额控制服务**：Flask 网页 + SQLite 版本库，向代理推送配额并跟踪确认 |
| `receiver/` | 本地接收器，原样回显报文，可延迟回包 |
| `docker-compose.yml` | 一键启动接收器 A/B + 代理 + 配额控制服务 |
| `scripts/verify_local.py` | 无 Docker 环境下的端到端行为验证（约 60 项检查） |

## 启动

```bash
docker compose up --build
```

- 代理操作网页：http://localhost:8080
- **配额控制网页：http://localhost:8081**
- 遥测终端发送地址：`UDP <宿主机>:9000`

## 配额控制（本次新增）

### 两个版本

- **保存版**：值班员在配额网页保存的最新设置，落在配额服务 SQLite。
- **代理已确认版（已生效）**：代理实际应用并回确认的版本。
- 保存后只有代理确认应用，网页才显示“已生效”；联系代理失败则保留为
  **待应用版**，后台每 2 秒重试，配额服务重启后仍会继续应用。
- 代理始终按**已应用**的配额接纳；保存失败（含越界输入、数据库故障）
  不改动当前版或待应用版。

### 配额规则（代理执行）

- **范围**：全局活动会话上限 2～16；单来源 IP 上限 1～8。
- **首包即计入**：会话从第一个数据包起（建连中）就占用名额。
- **单来源满额即拒绝**：该来源 IP 会话数达到上限时，新首包直接丢弃并记日志。
- **全局满额腾退**：全局满额时，若存在占有多于一席的来源，腾退其中
  **最久未活动（LRA）**的会话后接纳新会话；若各来源均仅一席则拒绝。
  被腾退会话的上游端口立即关闭并冷却，其迟到回包不可能投递。
- **收紧不踢旧会话**：新上限只影响之后的接纳；用量回落到新上限以下前
  不接纳新会话，已有会话照常透传。
- **名额归还**：会话空闲过期或建连失败时立即归还占用的名额。
- **重启门控**：代理重启后必须先从配额服务拉到保存版，才绑定 UDP 并
  接纳新会话；拉取失败则持续重试，期间首包一律丢弃。

### 配额网页功能（`quota/`，端口 8081）

- 设置全局上限（2～16）与单来源上限（1～8），保存为新版本；
- 并排展示**保存版**与**代理已确认版**（版本号、数值、状态、时间）；
- 显示代理连通状态、最近同步错误、代理侧实时用量与每来源会话数；
- 展示代理侧活动会话明细（每 2 秒自动刷新）。

## 代理网页（`proxy/`，端口 8080）

- **切换目标接收器** A/B（原切流能力保留）：只影响新会话，旧会话固定原接收器。
- **发送试传报文**：可选择**来源 IP（127.0.0.1～127.0.0.3）**与**源端口**
  （留空随机、填写则固定），另可设回包延迟与等待超时；结果显示实际去向、
  回包内容与 RTT，用于模拟异常终端更换源端口。
- **活动会话 / 报文日志**：实时显示每个会话的来源 IP、固定接收器、状态，
  以及配额拒绝、腾退等事件（每 2 秒自动刷新）。

## 转发与可靠性规则

- **会话**：按客户端 `IP:端口` 建立，空闲 5 秒（`SESSION_IDLE_TIMEOUT`）无收发即过期。
- **建会话固定接收器**：会话期间一切报文发往建会话那一刻的目标接收器。
- **原样透传**：报文与回包内容不做任何修改。
- **回包不错投 / 迟到回包**：每会话一条独立的、已 connect 的上游 UDP 套接字；
  会话关闭即关端口并进入冷却（`UPSTREAM_PORT_COOLDOWN`，默认 30 秒），
  旧会话迟到回包无法送达同 `IP:端口` 重建的新会话。
- **配额版本接口**（令牌 `X-Quota-Token`）：
  - 配额服务 `GET /quota/saved`：代理启动时拉取保存版；
  - 代理 `GET /admin/quota`、`POST /admin/quota/apply`：查询/应用配额。

## 接收器延迟回包

- 环境变量 `REPLY_DELAY`：该接收器所有回包的默认延迟秒数。
- 报文级覆盖：报文以 `DELAY:<秒>:` 开头时按该值延迟（回包仍是完整原始报文）。

## 配置（环境变量）

### 代理 `proxy/`

| 变量 | 默认 | 说明 |
|---|---|---|
| `UDP_LISTEN_PORT` | `9000` | 代理对终端的 UDP 监听端口 |
| `HTTP_PORT` | `8080` | 代理操作网页端口 |
| `SESSION_IDLE_TIMEOUT` | `5` | 会话空闲超时（秒） |
| `RECEIVER_A/B_HOST/PORT` | 见 compose | 接收器地址 |
| `DB_PATH` | `/data/proxy.db` | SQLite 路径（目标持久化） |
| `UPSTREAM_PORT_MIN/MAX` | `20000/29999` | 上游本地端口池 |
| `UPSTREAM_PORT_COOLDOWN` | `30` | 上游端口关闭后的冷却秒数 |
| `QUOTA_SERVICE_URL` | （compose 内 `http://quota:8081`） | 配额控制服务地址；留空则用内置默认配额 |
| `QUOTA_TOKEN` | `quota-shared-secret` | 管理接口共享令牌 |

### 配额服务 `quota/`

| 变量 | 默认 | 说明 |
|---|---|---|
| `HTTP_PORT` | `8081` | 配额控制网页端口 |
| `DB_PATH` | `/data/quota.db` | SQLite 路径（配额版本持久化） |
| `PROXY_BASE_URL` | `http://proxy:8080` | 代理管理接口地址 |
| `QUOTA_TOKEN` | `quota-shared-secret` | 管理接口共享令牌 |
| `SYNC_INTERVAL` | `2` | 推送/拉取代理状态的周期（秒） |

## 本地验证（无需 Docker）

```bash
pip install flask
python3 scripts/verify_local.py
```

覆盖：原样透传（含二进制）、A/B 切流旧会话固定、过期重建、迟到回包丢弃、
试传来源 IP/源端口选择；单来源满额拒绝、首包即计入、全局满额 LRA 腾退、
各来源一席时拒绝、被腾退会话迟到回包不投递、收紧不踢旧会话且回落前不接纳、
空闲/失败归还名额；保存版与已确认版、联系失败保留待应用版、双侧重启后继续
应用、代理重启先取保存版再接纳、越界输入与保存失败不改版本、管理接口鉴权。
